## Лабораторная 1. Мониторы
### Задание:
Требуется безопасно и эффективно реализовать монитор с двумя потоками: потоком-поставщиком и потоком-потребителем. Поток-поставщик должен с задержкой в одну секунду инициировать условное событие, о чём должен выводить сообщение на экран. Поток-потребитель должен это условное событие получать, о чём также должен сообщать на экране. В итоге на экране должна появляться серия чередующихся сообщений об отправлении события и его обработке. Сообщения не должны нарушать очерёдность. Ожидание события должно происходить с минимальным потреблением процессорного времени, т. е. быть практически равным нулю. Подразумевается, что условное событие может содержать несериализуемые данные (скажем, передаётся экземпляр класса по указателю).
### EventData (Событие)
Пользовательская структура, описывающая передаваемое событие.
Экземпляр создаётся в куче (new EventData(...)) в потоке-поставщике, а указатель на него передаётся через общую переменную data. Потребитель получает этот указатель, работает с полями id и payload и освобождает память через delete.
### producer (Поставщик)
Раз в секунду создаёт новое событие (экземпляр EventData в куче).
Под защитой мьютекса:
Проверяет, обработано ли предыдущее событие.
Если да — записывает указатель в общую переменную data.
Ставит флаг ready = 1.
Выводит сообщение.
Будит потребителя через pthread_cond_signal.
Если событие ещё не обработано — просто ждёт следующей секунды.
### consumer (Потребитель)
В цикле ждёт появления события (while (ready == 0)).
Если данных нет — вызывает pthread_cond_wait, который временно отпускает мьютекс и усыпляет поток (не нагружая CPU).
Когда поставщик его будит: Забирает указатель, сбрасывает ready = 0, выводит сообщение, удаляет объект из памяти, отпускает мьютекс.
### main
<li>Запускает оба потока (pthread_create).</li>
<li>Спит 5 секунд, давая потокам поработать.</li>
<li>Инициирует завершение: ставит флаг stopping = true и вызывает pthread_cond_broadcast, чтобы разбудить потребителя.</li>
<li>Дожидается завершения потоков (pthread_join).</li>
<li>Удаляет оставшиеся данные (если есть) и уничтожает мьютекс с условной переменной.</li>
